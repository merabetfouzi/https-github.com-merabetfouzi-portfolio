# Portfolio Website

A modern, minimalist portfolio website built with Node.js and Express.

## Features

- **Project Gallery**: Showcase projects with images and descriptions.
- **Admin Dashboard**: Manage portfolio content through a block-based editor.
- **Responsive Design**: Optimized for all devices.
- **Vercel Ready**: Configuration included for easy deployment.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Access the site at `http://localhost:4000` and the dashboard at `http://localhost:4000/dashboard.html`.

## Deployment

This project is configured for deployment on Vercel.
